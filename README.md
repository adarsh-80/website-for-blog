# The Living Book — V1

A minimalistic, scroll-based personal publication.

## Run locally
Open `index.html` in a browser.

## Deploy
Upload these files to your GitHub repository and import/connect the repository in Vercel.

## Publishing model
For V1, add another `<section class="content-section">` to `index.html` and add its title to the TOC. Later this can be replaced with Markdown/CMS/database publishing without changing the reading experience.
