# V1.6 — The Evolution of Intelligence

This folder is the second webpage for The Living Book.

## Installation

Copy this entire `v1.6` folder into the existing website's `pages/` directory:

    the-living-book-final/
    └── pages/
        ├── human-agi.html
        └── v1.6/
            ├── index.html
            ├── style.css
            ├── script.js
            └── README.md

Then add the V1.6 entry to the existing `site-data.js` file in the `versions` array.

Use this path for the webpage:

    pages/v1.6/index.html
